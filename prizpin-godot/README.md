# Prizpin (Godot sürümü, ilk deneme)

Godot 4.3 veya daha yenisiyle açılır.

1. Godot'yu indir: https://godotengine.org/download (Windows, "Standard" sürüm, .NET olmayan).
2. Zip'ten çıkan klasörü kaydet, Godot'yu aç, "Import" / "İçe aktar" de, bu klasördeki `project.godot` dosyasını seç.
3. Açılınca sağ üstteki oynat düğmesine (veya F5) bas.
4. Fareyle küpün bir parçasını sürükle: katman döner. Boş yeri sürükle: küp döner. Karıştır, Geri Al, − ve + düğmeleri çalışır.

Bu sürümde: yalnızca 3×3, Türkçe, süre ve hamle sayacı, en iyi süre kaydı.
